# Aerie's default scenes

Blender scenes exported as glTF (`.glb`) go here; they are Aerie's default themes and show up
first in the Library and the hub. See [docs/BLENDER.md](../../docs/BLENDER.md) for how to make
and export them.

For each scene: `name.glb`, optionally `name.jpg` (16:9 preview) and `name.json`
(`{"title": "…", "tagline": "…", "order": 1, "credits": "…"}`).
